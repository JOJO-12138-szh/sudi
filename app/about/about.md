**二、打印机任务调度系统 2025/10**

**技术栈：**C、动态数组、**最小堆**、优先队列、**动态内存管理**、Linux时间库

 

**技术架构：**

1. 基于最小堆的优先队列实现任务调度

2. 三级调度策略：优先级 → 页数 → 提交时间

3. 动态扩容/缩容机制（自动适配负载）

**任务描述：**

1. 使用**最小堆（Min-Heap）**实现优先队列，以 O(log n) 时间复杂度完成任务插入和取出

2. 设计**三级优先级调度算法**：先按用户优先级（1-10），再按页数（短作业优先），最后按提交时间**（FIFO）**，兼顾公平性与效率

3. 实现动态扩容/缩容机制：队列满时自动扩容至 2 倍，使用率低于 25% 时自动缩容，平衡内存与性能

4. 提供完整任务管理功能：提交任务、执行打印（取出堆顶）、查看所有任务（堆排序输出）、撤销任务（O(n)查找 + O(log n)调整）、调整优先级

5. 实现 O(n) 建堆优化：查看所有任务时，**临时复制堆数据**并原地建堆，不破坏原堆结构

6. 实现任务撤销后的**堆自愈**：根据优先级变化方向选择上浮（siftUp）或下沉（heapify）调整，维护堆性质

 

**三、基于STM32的麦克纳姆轮小车 2026/1**

**技术栈：**STM32、C、蓝牙串口通信、PWM、GPIO、有限状态机（FSM）

 

**技术架构：**

硬件层：STM32主控 + **麦克纳姆轮**底盘 + 红外反射式传感器阵列（循迹/避障） + **蓝牙模块**

驱动层：四路独立PWM电机驱动、GPIO数字信号采集、串口DMA通信

应用层：**有限状态机（FSM）**决策逻辑、运动学解算、遥控/自主模式切换

 

**任务描述：**

1. 建立四轮独立驱动控制模型，通过四路PWM分别控制四个麦克纳姆轮，结合**运动学解算**，实现原地旋转、横向平移、斜向移动等全向运动模式

2. 设计双路红外传感器循迹算法，采用**有限状态机（FSM）**决策架构，将传感器信号映射为差速控制指令，使小车沿指定路径稳定行驶

3. 集成红外避障功能，通过GPIO中断实时检测障碍物信号，实现自主避障与路径重规划

4. 通过蓝牙串口与手机APP通信，实现遥控/自主双模式切换与实时状态监控
